# Projecto em português

Projecto web criado com Lovable. O conteúdo visível da interface está a ser traduzido para português.

Este projecto foi criado com [Lovable](https://lovable.dev).

## Continuar a desenvolver com o Lovable

Continue a desenvolver este projecto no [editor do Lovable](https://lovable.dev/projects/eca69c53-ec11-4dbc-a315-8b9352500776).

- **Desenvolvimento mais rápido**: descreva o que pretende criar e o Lovable trata do código.
- **Sincronização automática**: cada alteração feita no Lovable é guardada directamente neste repositório.
- **Propriedade total**: o código é seu. Envie as alterações para a branch `main` do GitHub para as sincronizar com o Lovable.

## Desenvolvimento local

Prefere trabalhar no seu computador? Precisa de Node.js e npm — [instale com nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <url-deste-repositorio>
cd <nome-do-repositorio>
npm i
npm run dev
```
